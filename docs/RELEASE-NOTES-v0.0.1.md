# HoopoeTV v0.0.1 发布说明（build50）

- 包名：`com.hoopoetv.tvbox`
- 版本：`versionName v0.0.1` / `versionCode 1`
- 构建变体：`arm64` + `generic` + `debug`（apk 内文件名 `TVBox_debug-arm64-generic-java.apk`）
- 体积：38,402,016 字节（约 36.6 MB）
- 编译时间：2026-11-09 17:27
- 安装包位置：仓库 `dist/HoopoeTV-v0.0.1-build50-arm64-debug.apk`

## 本版包含

### 品牌
- 应用名 HoopoeTV，包名 `com.hoopoetv.tvbox`（海信变体 `com.hoopoetv.tvbox.hisense`）
- 新图标（512×512）、新横幅（640×360）、三张 1920×1080 壁纸
- 关于页免责声明改为学习测试用途说明

### 空壳播放器化
- 内置视频源 / 直播源 / 节目单地址全部清空为空字符串
- 删除内置 `assets/epg_data.json`（4924 行）
- 首次启动自动清空 Hawk 中残留的 `API_URL` / `LIVE_URL` / `EPG_URL`（标记 `shell_url_reset_v1`）
- `JarLoader` 兼容不含 `com.github.catvod.spider.Init` 的 `spider.jar`（DecoTV 等分发）

### 首页结构
- 顶部左侧「应用」长方形块 vs_140×vs_70（图标上、文字下），与右侧六键等高
- 顶部右侧六键：首页 / 直播 / 收藏 / 文件 / 历史 / 推送，高度统一 vs_70、weight=1 均分、图标+文字整组居中
- 左上角数据源名称可点，弹出「请选择数据源」列表（按源数 1~3 列），选中即生效并自动关闭、重载首页；无源提示
- 左右分栏：左栏导航 vs_214，右栏内容区「纸面」质感（20mm 圆角、淡白底 + 描边）

### 左侧导航（拨轮）
- 分类从顶部横排移到左栏竖排，固定定位，可上下滚动
- 可视框高度 vs_370（约 7 项，第 8 项渐隐），上下各 vs_30 渐变遮罩
- 菜单项等宽（6 汉字宽度，`mm2px(160)`），短/长标签块宽一致
- 菜单间外间距由 `shape_left_item.xml` 上下内缩 7dp 实现
- 选中：主题色底 + 2mm 白边；未选中：深灰半透明无描边；文字 `0xE6FFFFFF`

### 底部分类筛选条
- 类型 / 地区 / 排序 / 年代 动态生成，默认关闭
- 再点同一分类开合；返回键优先关闭该条
- 磨砂背景 `shape_filter_panel`（`#CC141414` + 0.5mm 描边）

### 交互
- 切页过渡：右侧内容 alpha 0.4 + Y 轴位移 `mm2px(25)`，260ms Decelerate；左栏 alpha 0.4→1（220ms）
- 任意页面连按两次返回键退出 App（2 秒内第二次生效）
- 返回键优先级：加载中刷新 → 退出多选 → 关闭底部分类条 → 页面越界回退 → 两次退出

### 设置页
- 主题切换、语言切换隐藏（锁定默认主题 + 简体中文）
- 系统分组新增「清理缓存」：右侧显示占用大小，点击清理并刷新 + toast
- 旧的 `llHomeIcon` 清理入口置为 GONE

## 安装

1. 下载 `dist/HoopoeTV-v0.0.1-build50-arm64-debug.apk`
2. 仅适用于 arm64 设备（Android 5.0+，targetSdk 28）
3. 与上游 TVBox 同包名体系不同（`com.hoopoetv.tvbox`），可与原版共存
4. 首次启动无任何内置源，需在「设置 → 配置地址」自行填写视频源

## 已知限制

- `versionCode` 仍为 1，未做 release 签名（当前为 debug 签名，仅供内测）
- 首页若出现「未知条目」空卡片，是对应数据源返回空列表，非界面问题
- 绿灯/榜单等分类的实际可用性取决于所填数据源
